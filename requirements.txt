# Muninn has NO third-party Python dependencies.
#
# The entire runtime and test path uses only the Python 3.10+ standard library
# (http.server, sqlite3, urllib, json, hmac, secrets, unittest). There is nothing to
# install — "zero-install" is a real property, not a goal:
#
#   python3 -m backend.server      # run
#   make test                      # test
#
# This file is intentionally dependency-free. Do not add pins here unless a genuine
# third-party import is introduced into the runtime path; adding one would break the
# zero-install guarantee the README relies on.
